genuinely consumed. `proved-standalone` — proved, but not imported by the main chain.
`named-imported-estimate` — explicit named hypothesis for an external result
([2]/[7]/[9]/[10]), not a proof. `formalization-gap` — not yet formalized.
`named-construction-input` — explicit named hypothesis for the paper's §§6–9
construction or a per-subtree analytic input; not proved, precisely documented.

the OLD simplified path and the NEW faithful path (which supersedes it).

## Known gaps

1. **Trivial history tree (OLD path only).** The OLD `scalar_closure` descent runs on `trivialTree` (root `[]` with one leaf `[t]` per tube), not the paper's geometric multi-scale history tree; there `Xdup = 0` and the genuine duplicate closure is never exercised. The NEW faithful path (`faithful_gate_wired`, `faithful_gate_discharged`, `scalar_closure_discharged`) works on GENERAL history trees with the exact duplicate identity (146) proved — but the §§6–9 *construction* of that tree from a tube family (`DescentLabels`, leaf data, per-subtree analytic inputs) is still a named input, not built.
2. **Remaining named inputs of the end-to-end.** `scalar_closure_discharged` is `Hpred`-free, but takes as named hypotheses: `DescentLabels T lab` (§§6–9 construction), pointwise `leaf_bound` (53), per-subtree `terminal_hardening : ∀ x ∈ T, …` (R5 (148) re-run per subtree; the (θ,j,c) data is root-only), per-subtree `geom_pair : ∀ x ∈ T, …` (root instance from H2/H3/H4 via `faithful_geom_pair`; subtree versions named), and the bridge `htotalLoad` ((136)+(145)). The exact obstruction to also proving the root `terminal_hardening` from the model data in subpower form is documented in `Thm_FilteredDescent_EndToEnd.lean` (`hquant` pins `Bpred` from below; the re-proof must be fused into the descent to avoid circularity).
3. **Standalone modules.** Insertion kernels, Cauchy–Binet, pivot dichotomy, support recurrence, duplicate closure (old toy), LCA reduction, and the unweighted-projection counterexample are proved but not wired into the main chain. R5 is genuinely consumed by `terminal_hardening` (§10.3), whose root instance is wired into `faithful_gate_wired`.
4. **Typed route excluded.** The Hall-capacity comparison (160)/(207) is not formalized and is explicitly excluded from the scalar closure; it carries the independent Hall/Radon–Nikodym positivity requirement the paper does not claim.
5. **Deep estimates are hypotheses.** [2] (planar Córdoba), [7,10] (sticky + sticky/non-sticky), [9] (marked 4D) enter only as named assumptions; only their *consumption* by the descent is proved. d ≥ 5 is unclaimed.
6. **Physical model: direction separation is model data.** `physicalRealization` builds a genuine `ShadedTubes` from real δ-tubes and is now consumed by `scalar_closure_discharged_physical`, but the sticky/marked geometric structure behind the H2/H3/H4 standing hypotheses is not modeled — the inputs stay named.
7. **Axiom audit.** `#print axioms` re-run 2026-10-02 on all top theorems (`scalar_closure_discharged`, `scalar_closure_discharged_physical`, `scalar_closure_faithful`, `scalar_closure_physical`, `descent_bound`, `faithful_gate_discharged`): only `[propext, Classical.choice, Quot.sound]` throughout.
